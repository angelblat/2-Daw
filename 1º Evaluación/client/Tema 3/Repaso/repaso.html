Ejercicios JavaScript - Arrays y objetos

Ejercicio 1 - Productos disponibles

A partir del array productos:

  1. Utiliza filter para obtener los productos que tengan stock superior a 0.
  2. Utiliza map para crear un nuevo array con los nombres de esos productos.
  3. Muestra el resultado por consola.

Ejercicio 2 - Media de notas

A partir del array alumnos:

  1. Filtra los alumnos que hayan aprobado (nota igual o superior a 5).
  2. Calcula la suma de sus notas utilizando reduce.
  3. Calcula la media de los alumnos aprobados.
  4. Muestra por consola la media final.

Ejercicio 3 - Búsqueda y modificación

A partir del array usuarios:

  1. Utiliza find para localizar al usuario con el nombre "Carlos".
  2. Cambia su propiedad activo a true.
  3. Muestra el objeto del usuario modificado.

Ejercicio 4 - Facturación de ventas

A partir del array ventas:

  1. Filtra únicamente las ventas del departamento "Informática".
  2. Utiliza reduce para calcular el importe total de esas ventas, multiplicando precio por cantidad.
  3. Muestra el importe total por consola.

Ejercicio 5 - Gestión de empleados

A partir del array empleados:

  1. Filtra los empleados que estén activos y tengan 18 años o más.
  2. Utiliza forEach para mostrar un mensaje por cada empleado con su nombre y edad.
  3. El formato debe ser: "Nombre: Ana - Edad: 25".

Ejercicio 6 - Resumen de pedidos

A partir del array pedidos:

  1. Utiliza map para crear un nuevo array de objetos.
  2. Cada objeto debe contener el nombre del cliente y el importe total del pedido (precio por cantidad).
  3. Añade una propiedad estado: "Pedido grande" si el importe supera los 100 euros y "Pedido pequeño" en caso contrario.
  4. Muestra el nuevo array por consola.

Ejercicio 7 - Salarios por departamento

A partir del array trabajadores:

  1. Filtra los trabajadores del departamento "Desarrollo".
  2. Utiliza map para obtener únicamente sus salarios.
  3. Utiliza reduce para calcular el salario total.
  4. Muestra el salario total y el número de trabajadores del departamento.

Ejercicio 8 - Gestión de biblioteca

A partir del array libros:

  1. Filtra los libros que estén disponibles.
  2. De esos libros, filtra los que tengan más de 300 páginas.
  3. Utiliza reduce para calcular el número total de páginas de esos libros.
  4. Utiliza find para localizar el primer libro cuyo autor sea "George Orwell".
  5. Muestra todos los resultados por consola.
